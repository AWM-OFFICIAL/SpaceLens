## Full description

SpaceLens is a Windows storage analyzer and cleanup assistant. It maps what fills your drives, explains why, and only deletes after you confirm.

What you get
• Full PC or folder scans with live progress
• Clearest view of largest files, folders, Downloads, and old untouched files
• Transparent risk labels: SAFE, REVIEW, PROTECTED, UNKNOWN
• Cleanup suggestions that never one-click delete protected system or personal paths
• Duplicate detection by size and content hash — you decide what stays
• Development artifact finder (node_modules, build caches, and more)
• Application storage estimates (analysis only — SpaceLens does not uninstall apps)
• Local scan history trends — sizes and category totals only, never file contents
• Dark and light themes, export to HTML / JSON / CSV

Privacy by design
Your files stay on your computer. SpaceLens does not upload paths, metadata, or contents. There is no cloud processing and no telemetry by default.

Safety first
Default cleanup moves items to the Windows Recycle Bin. Permanent delete requires two confirmations. Protected locations are blocked.

Perfect for
• Freeing space before a Windows upgrade or large install
• Finding leftover Downloads and regeneratable developer folders
• Understanding where disk space actually went — without scary one-click cleaners

Requirements: Windows 10 or Windows 11 (x64)

## Privacy policy (short, for listing URL page)
SpaceLens performs storage analysis entirely on your device. It does not collect, transmit, or sell personal data. Optional local history stores only aggregate sizes and category totals. Crash logs, if any, are written only under %LocalAppData%\SpaceLens\logs on this PC. You can clear history and open the data folder from Privacy in the app.
